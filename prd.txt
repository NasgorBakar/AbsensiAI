Buatkan saya aplikasi **absensi siswa berbasis web menggunakan Python Flask dengan AI Face Recognition dan Firebase Firestore sebagai database**.

## Teknologi:

* Backend: Python Flask
* AI: OpenCV + Face Recognition
* Database: Firebase Firestore
* Frontend: HTML, CSS, JavaScript, Bootstrap
* Authentication: Firebase Authentication

## Fitur Utama:

### 1. Role Siswa

Siswa dapat:

* Login.
* Melakukan absensi menggunakan kamera.
* Sistem mengenali wajah siswa.
* Data absensi tersimpan otomatis ke Firebase.
* Melihat riwayat absensi sendiri.

Data absensi:

* Nama siswa
* ID siswa
* Tanggal
* Jam masuk
* Status (Hadir/Terlambat)

---

### 2. Role Admin

Admin dapat:

* Login.
* Melihat dashboard.
* Melihat daftar siswa.
* Mendaftarkan wajah siswa.
* Melihat data absensi semua siswa.
* Melihat laporan absensi berdasarkan tanggal.

---

## Sistem Face Recognition

Alur:

1. Admin mendaftarkan wajah siswa menggunakan kamera.
2. Sistem membuat face encoding/embedding.
3. Data wajah disimpan ke Firebase Firestore.
4. Saat absensi:

   * Kamera aktif.
   * Sistem mendeteksi wajah.
   * Wajah dicocokkan dengan data Firebase.
   * Jika cocok, absensi otomatis dibuat.
   * Jika tidak cocok, tampilkan pesan gagal.

Tambahkan:

* Pencegahan absensi dua kali dalam satu hari.
* Threshold pengenalan wajah.
* Validasi hanya satu wajah dalam kamera.
